# 星際回合戰

科幻題材的簡易回合制 RPG，純 HTML／CSS／JavaScript（Canvas）製作，不需要建置，透過 GitHub Actions 部署到 GitHub Pages。

## 玩法

1. 選擇職業：**裝甲戰士**（耐打、物理強）或**能量法師**（脆弱、魔法強）。
2. 回合制戰鬥，每回合三選一：
   - **物理攻擊**：不消耗 MP
   - **魔法**：消耗 MP，較能穿透敵人防禦
   - **防禦**：本回合受到的傷害減半，並回復 MP
3. 操作：滑鼠／觸控點按鈕，或按鍵盤 `1`、`2`、`3`。

## 開發進度

- [x] 第一階段：選職業、與一隻敵人的回合制戰鬥、勝負判定
- [ ] 第二階段：敵人序列與魔王、戰鬥間的強化與回復、破關畫面
- [ ] 第三階段：開場白、畫面效果、數值平衡

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `js/data.js` | 職業、敵人與戰鬥規則數值（調整平衡改這裡） |
| `js/battle.js` | 戰鬥邏輯，不涉及畫面 |
| `js/render.js` | Canvas 戰鬥畫面繪製 |
| `js/main.js` | 畫面流程與操作 |

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## 部署

推送到預設分支後，`.github/workflows/pages.yml` 會自動部署。
第一次使用前，請到 repo 的 **Settings → Pages**，將 **Source** 設為 **GitHub Actions**。
